# Air Guitar

A planned webcam-controlled virtual guitar using Python and hand tracking.

## Status
Project planning and repository setup. Gesture detection and audio playback are not implemented yet.

## First prototype
- Track both hands using the laptop camera.
- Select C, G, Am, and F with simple left-hand gestures.
- Trigger a guitar chord with a right-hand downward strum.
- Display the selected chord and prevent repeated triggers from one strum.

## Milestones
1. Camera preview and hand tracking.
2. One strum plays one chord.
3. Four chord gestures and visual feedback.
4. Tune responsiveness and document limitations.
5. Record a demo and publish measured results.

## Development workflow
Make a focused change, test it, commit it with a descriptive message, then push to GitHub.
